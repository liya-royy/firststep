# FirstStep 🚀
Zero experience required. Your first real opportunity starts here.

## What it does
Connects fresh graduates with small businesses who need beginner-friendly micro-tasks done.

## How to run
1. cd Backend
2. pip install flask flask-cors
3. python app.py
4. Open Frontend/index.html in browser

## Built with
- HTML, CSS, JavaScript (Frontend)
- Python Flask (Backend)
- JSON file storage
